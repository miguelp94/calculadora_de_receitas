# calculadora_de_receitas
Automatização em python para recalcular ingredientes em uma receita dada uma variação de pessoas. 

Arquitetura: Integração de LLM para atuar como um parser de dados desestruturados.

Foco Técnico: Uso de Prompt Engineering para forçar outputs determinísticos em JSON, tratamento de erros e integração via API.

Próximos passos (para mostrar visão de engenharia): Transformar esse script em uma API REST usando FastAPI para que um aplicativo web pudesse consumi-lo.
